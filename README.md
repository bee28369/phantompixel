# PhantomPixel 🛡️🕵️

> **Seen by people. Invisible to AI.**  
> Protect your photos and PDF documents from AI vision scrapers and embed secret invisible watermarks to prove ownership.

---

## Features
- **Anti-Vision LLM Cloaking:** Injects microscopic mathematical color perturbations that disrupt AI Vision models and OCR scanners while keeping the image 100% crisp and clear to human eyes.
- **Invisible Watermark (Steganography):** Embeds an invisible owner signature / copyright note directly into pixels or PDF text encoding without degrading quality.
- **Full Resolution Preserved:** Never shrinks or compresses resolution—4K and 8K images remain 1:1 original quality.
- **PDF Document Support:** Protects both raster images and PDF pitch decks / contracts / screens.
- **Check File / Verifier Mode:** Upload any protected file to instantly extract and reveal the hidden ownership signature.
- **iOS & Android Ready:** Built with responsive mobile views, PWA offline support, and Capacitor config for App Store & Google Play distribution.

---

## Quick Start

### Run with Node.js:
```bash
npm start
```
Then open [http://localhost:8080](http://localhost:8080) in your browser.

### Run with Python:
```bash
python3 server.py
```
